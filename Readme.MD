# MMSD25 (Public Reference Subset) – Multi-Modal Shrimp Disease Dataset 2025

This repository provides the **public sanitized reference subset** of MMSD25 and the **benchmark protocol** (preprocessing, splits, evaluation scripts) for reproducibility. :contentReference[oaicite:1]{index=1}

## What is released (public)
- A **sanitized reference subset** for non-commercial research
- Benchmark protocol: preprocessing + splits + evaluation scripts :contentReference[oaicite:2]{index=2}

## What is NOT released
- The **full MMSD25 dataset is NOT publicly available** due to farm partner agreements. :contentReference[oaicite:3]{index=3}

## Dataset context (from the paper)
MMSD25 is a real-world multimodal dataset collected from shrimp farms, integrating:
- RGB images
- Farmer-written text descriptions
- Environmental sensor streams (e.g., temperature, pH, dissolved oxygen, turbidity) :contentReference[oaicite:4]{index=4}
